# LotoSystem Stage 02 Prompt

Stage 02 adds domain models, lottery rules, and the deterministic statistical research engine for LOTO6 and Mini Loto.

Required output:

- LOTO6 and Mini Loto rule definitions
- Core domain models
- Ticket and draw validation
- Canonical ticket representation
- Tests for domain behavior
- Historical data loading and validation
- Deterministic statistics
- Deterministic features
- Research candidate generation and transparent scoring
- Walk-forward backtesting and baseline comparison
- JSON persistence
- Offline CLI
- Documentation updates

Do not implement machine learning, data scraping, databases, prize matching, scheduling, LLM integrations, frontend functionality, or automatic purchasing in this stage.
